## 最终系统能力

```
data_fetcher（行情+指标）→ scoring（三引擎评分）→ signal_backtest（买卖信号+回测）
```

- **数据**：yfinance 真实拉取（fallback 模拟），250 日线 + MA20/50/200/RSI14/ATR14
- **评分**：综合分 = 0.4 基本面 + 0.3 技术面 + 0.2 情绪 + 0.1 宏观（0-100）
- **信号**：买入≥3 项（综合分>75/金叉/RSI/情绪）、卖出≥2 项（001 十章条件）
- **回测**：2018-2025 模拟组合，年化/夏普/回撤/信号次数（真实数据接入后可评估）

## 运行方式

```bash
cd stock-system
python data_fetcher.py        # V1：数据+指标
python scoring.py             # V2：三引擎评分
python signal_backtest.py     # V3：信号+回测
```
