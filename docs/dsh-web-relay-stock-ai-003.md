# 股票智能系统 · V2 隔离试错机制（003）

> 范式跃迁 V2：沙箱隔离层 + 回放引擎 + Gate 评估

## 一、实现

- **沙箱隔离层**：`stock-system/sandbox.py`——策略变体（评分权重/RSI 阈值/止损 ATR 倍数组合）在隔离回放中独立试错
- **回放引擎**：模拟 250 交易日收益序列，计算年化/夏普/最大回撤
- **Gate 评估**：`sharpe ≥ 0.8 且 回撤 ≤ 25%` 才物化入主策略池；失败变体仅消耗沙箱配额（并发 ≤2）
- **主策略池**：生产态，仅收纳通过 Gate 的变体

## 二、运行结果（原型验证）

```
[沙箱] 并发配额 2，变体入沙箱试错...
  ❌ base 失败（sharpe=-0.04, dd=21.51%）→ 仅消耗配额，未污染生产态
  ✅ momentum-heavy 通过 Gate（sharpe=5.35, dd=9.14%）→ 物化入主策略池
  ❌ value-heavy 失败（sharpe=-0.32, dd=34.23%）→ 仅消耗配额
  ❌ aggressive 失败（sharpe=-0.01, dd=17.55%）→ 仅消耗配额
[主策略池] pool_size=1 [momentum-heavy] failed_count=3
```

**验证结论**：失败变体未进入生产态 → 隔离试错机制有效（零污染）
