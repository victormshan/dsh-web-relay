# 北美市场自动选股/选基系统 · V1 方案文本

> dsh-web-relay V1.9 AutoIteration（5 版）· V1 版
> 外部 AI 方案（dialog 通道输出）→ 主 agent 落盘

## 一、系统目标

为北美市场个人投资者构建**全自动选股/选基系统**，基于财经新闻、财报、行情数据与预测模型，每日输出：

- 候选投资标的清单（股票 + ETF）
- 每只标的的多因子评分与逻辑解释
- 明确的买入/卖出时机信号
- 风险控制建议与仓位提示

## 二、系统架构

```
[数据采集层] → [分析引擎层] → [信号生成层] → [输出/执行层]
```

### 2.1 数据采集层

| 数据类型 | 来源 | 频率 | 说明 |
|---------|------|------|------|
| 日线行情 | yfinance / Polygon.io | 每日收盘后 | OHLCV、成交量、复权价 |
| 财务报告 | SEC EDGAR API | 10-K(年报)、10-Q(季报) | 收入、利润、现金流、资产负债表 |
| 财经新闻 | NewsAPI / GDELT | 实时(每小时) | 标题+正文，按股票代码过滤 |
| 社交媒体情绪 | StockTwits / Reddit API | 每小时 | 讨论热度与偏度 |
| 宏观数据 | FRED API | 每日/每周 | 利率、CPI、PMI |

### 2.2 分析引擎层

1. **基本面评分**（权重 40%）
   - 盈利指标：ROE > 15%、毛利率 > 30%、净利率 > 10%
   - 成长指标：营收 YoY > 10%、EPS YoY > 10%
   - 估值指标：P/E（行业相对）、PEG < 1.5、EV/EBITDA
   - 财务健康：资产负债率 < 60%、流动比率 > 1.5、自由现金流为正

2. **技术面评分**（权重 30%）
   - 趋势：MA50 > MA200（金叉状态）
   - 动量：RSI(14) 在 45-65 之间为健康；MACD 柱状图放大
   - 波动率：ATR(14) 正常范围内；布林带宽度
   - 量价：放量上涨、缩量回调确认

3. **情绪面评分**（权重 20%）
   - 新闻情绪：FinBERT 情感得分（-1 到 +1），近 7 天加权平均
   - 社媒情绪：看涨/看跌比例、讨论量变化率
   - 异常事件：突发新闻、分析师评级调整

4. **宏观/行业**（权重 10%）
   - 板块相对强度（RS 排名）
   - 利率敏感度、行业周期位置

### 2.3 信号生成层

- **综合评分**：加权总分 = 0.4×基本面 + 0.3×技术面 + 0.2×情绪面 + 0.1×宏观
- 每日全市场扫描 → 生成 Top 20 候选清单
- ETF 筛选：规模 > 10 亿美元、流动性充足、费用率 < 0.5%

**买入信号**（需满足至少 3 项）：
1. 综合评分 > 75 分
2. 技术面出现金叉（MA50 上穿 MA200）
3. RSI 从超卖区（< 35）回升至 40+，且成交量放大
4. 新闻情绪最近 3 天持续为正
5. 价格站稳关键支撑位（布林带中轨）

**卖出信号**（满足任 2 项）：
1. 综合评分 < 40 分
2. 死叉（MA50 下穿 MA200）
3. RSI > 75 且掉头向下
4. 新闻情绪转负且持续 3 天
5. 触及移动止损（ATR 2 倍 / 最大回撤 15%）

### 2.4 输出/执行层

- 每日报告：Markdown/HTML 邮件推送（Telegram/Email）
- 持仓监控：每 15 分钟检查止盈止损
- 模拟交易：Alpaca Paper Trading 验证信号
- 实盘（可选）：Alpaca/IBKR API 一键执行

## 三、风控体系

1. 单一标的仓位 ≤ 总资金 10%
2. 单一板块总仓位 ≤ 25%
3. 止损纪律：ETFs 单笔最大亏损 8%，个股 12%
4. 每日最大回撤超 3% → 降杠杆/减仓半仓
5. 周度再平衡

## 四、技术选型

- **语言**：Python 3.11+
- **数据处理**：pandas / polars
- **行情获取**：yfinance（备选：alpaca-py）
- **财报获取**：sec-edgar-api 或 EDGAR 官方 REST API
- **新闻情绪**：transformers + FinBERT（或 OpenAI API 摘要）
- **回测**：backtrader / vectorbt
- **调度**：cron / GitHub Actions（每日 17:00 ET 运行）
- **存储**：SQLite（起步）→ PostgreSQL（扩展）
- **通知**：Telegram Bot / 邮件
- **实盘**：Alpaca Trading API（美国券商，免费开户）

## 五、迭代计划（V1.9 AutoIteration，5 版）

- **V1（本版）**：方案文本设计 — 架构、数据源、分析逻辑、风控

- **V3**：分析引擎 — 基本面/技术面/情绪评分算法实现
- **V4**：信号生成+回测 — 买卖信号公式、历史回测验证
- **V5**：部署+监控+实盘对接 — 每日自动化运行、告警、paper trading

## 六、落地优先级

## 八、数据层设计（V2）

### 8.1 数据采集管道

| 数据源 | 采集方式 | 频率 | 依赖/库 |
|---|---|---|---|
| 日线行情 | yfinance 批量拉取（股票+ETF 代码表） | 每日收盘后 17:00 ET | yfinance |
| 财务报告 | SEC EDGAR submissions API（10-K/10-Q 索引 + 字段） | 季度（财报日触发） | sec-edgar-api / requests |
| 财经新闻 | NewsAPI 按代码过滤 / GDELT 流式 | 每小时 | requests |
| 宏观数据 | FRED API（利率/CPI/PMI 序列） | 每日/每周 | fredapi |

### 8.2 清洗规则

- **行情**：剔除停牌日缺失行、前复权校准、OHLC 空值前向填充（限 3 日）、成交量异常（>10σ）标记
- **财报**：SEC 原始字段→统一 schema 映射（revenue/net_income/eps/assets/debt/free_cash_flow）、缺失披露（如未按期申报）标记为 null 不推断
- **新闻**：按 ticker 过滤、标题+正文去重（simhash）、语言过滤（EN 为主）、相关度打分（代码提及次数）
- **宏观**：季度化对齐（月度序列转季度均值）、缺口线性插值（限 2 期）

### 8.3 字段 Schema（SQLite 表 DDL 草案）

`sql
-- 行情表
CREATE TABLE prices (symbol TEXT, date TEXT, open REAL, high REAL, low REAL, close REAL, adj_close REAL, volume INTEGER, PRIMARY KEY (symbol, date));
-- 财报表（季度）
CREATE TABLE fundamentals (symbol TEXT, period TEXT, revenue REAL, net_income REAL, eps REAL, total_assets REAL, total_liabilities REAL, free_cash_flow REAL, PRIMARY KEY (symbol, period));
-- 新闻表
CREATE TABLE news (id INTEGER PRIMARY KEY, symbol TEXT, ts TEXT, title TEXT, body TEXT, sentiment REAL, relevance REAL);
-- 宏观表
CREATE TABLE macro (series TEXT, date TEXT, value REAL, PRIMARY KEY (series, date));
`

### 8.4 增量更新策略

- 行情：每日增量（T-1 收盘），周末/节假日跳过
- 财报：按财报日历增量（新 10-K/10-Q 发布即拉）
- 新闻：每小时增量（游标=上次最大 ts）
- 宏观：按发布日历增量
- 全量重跑：--rebuild 标志触发（重建表 + 全量拉取，用于 schema 变更后）

> V2 自检：数据层覆盖 4 源采集/清洗/schema/存储/增量 5 要素齐全。


## 九、分析引擎设计（V3）

### 9.1 评分体系

综合分 = 0.4×基本面 + 0.3×技术面 + 0.2×情绪面 + 0.1×宏观（各因子 min-max 归一化至 0-100）

### 9.2 基本面引擎（权重 40%）

| 指标 | 健康阈值 | 得分规则 |
|---|---|---|
| ROE | >15% | 线性 0-100（>25% 满分） |
| 毛利率 | >30% | 同上 |
| 营收 YoY | >10% | 同上 |
| EPS YoY | >10% | 同上 |
| PEG | <1.5 | 1.5-2 减半，>2 为 0 |
| 资产负债率 | <60% | >70% 为 0 |
| 自由现金流 | 正 | 负则扣 20 分 |

### 9.3 技术面引擎（权重 30%）

- 趋势：MA50 > MA200 记 40 分，金叉 +10
- 动量：RSI(14) 45-65 记满分，35-45/65-75 记半，<35 或 >75 记 0（超卖回升加分）
- 波动率：ATR 处于 20 日正常带内满分
- 量价：放量上涨 +10，缩量回调 +5

### 9.4 情绪引擎（权重 20%）

- 新闻情绪：FinBERT 得分（-1~+1）近 7 天加权（旧 0.5 + 新 1.0），映射 0-100
- 备选：VADER（轻量）或 Gemini/OpenAI API 摘要打分
- 社媒偏度：看涨/看跌比例映射

### 9.5 预测模型（补齐需求 5）

- **财报前瞻**：基于历史季度营收/利润做线性/ARIMA 外推，与市场一致预期对比（缺口/超预期 → 调分）
- **价格动量预测**：短期（5-20 日）动量因子 + 波动率调整，输出未来 1 月方向概率
- 与信号层衔接：预测分进入综合分（V4 细化权重）

> V3 自检：评分公式可计算（归一化明确）、三引擎指标齐全、预测模型方案可行（需求 5 缺口闭合）。
