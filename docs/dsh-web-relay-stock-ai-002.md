# 股票智能系统 · 范式跃迁蓝图（V1）

> 基于 dsh-web-relay-stock-ai-001.md（12 章完备方案）的架构师突破期升级
> 范式：隔离试错 + 自我进化（突破设计师角色驱动）

## 一、范式转变

| 维度 | 001（旧范式） | 002（跃迁范式） |
|---|---|---|
| 策略产生 | 人工设计固定策略路由表 | 沙箱自动试错产生变体 → 元控制器进化 |
| 评估方式 | 一次性回测 | 持续回放评估（每次变体独立） |
| 演进机制 | 人工迭代 | 试错→评估→进化 闭环（元层自动） |
| 设计师角色 | 逐版设计 | 仅护栏维护（Guardian） |

## 二、四组件架构

```
[数据层(001八章)] → [回放引擎] → [沙箱隔离层] → [评估与 Gate]
                                       ↓
[生产策略池] ← [元控制器（进化闭环）] ← 绩效反馈
```

### 1. 沙箱隔离层（Isolation Sandbox）
- 策略变体在隔离工作区试错（复用 dsh-web-relay v3.0 影子沙盒思路：git worktree/独立空间）
- 变体 = 参数/规则/评分权重的组合（如 RSI 阈值、止损 ATR 倍数、权重分配）
- 失败变体只消耗沙箱配额（并发 ≤2、磁盘受限），不污染生产态

### 2. 回放引擎（Replay Engine）
- 历史行情回放 2018-2025（复用 001 回测框架数据）
- 每个变体独立回放：年化/夏普/回撤/胜率
- 支持样本外（2023-2025）验证

### 3. 元控制器（Meta Controller）
- 监听沙箱试错结果 + 生产绩效
- 自动调整策略权重与组合（进化算法：保留精英 + 变异 + 交叉）
- 输出：策略组合权重表、路由规则

### 4. 进化护栏（Evolution Guardrail）
- 风险约束：组合最大回撤 ≤15%、单标的 ≤10%、沙箱变体配额
- 护栏规则由 Guardian（设计师）维护，元层不可越权
- 越界自动熔断

## 三、与 001 架构挂载关系

| 001 模块 | 002 挂载 |
|---|---|
| 八章 数据层 | 保持，作为回放/沙箱数据源 |
| 九章 分析引擎 | 多策略变体化（评分权重可变） |
| 十章 信号层 | 由元控制器路由（替代固定路由表） |
| 十一章 部署层 | 沙箱/回放/元层纳入每日流水线 |
| 三章 风控 | 升级为进化护栏（Guardian 维护） |

## 四、V2-V5 迭代路线

- V2：隔离试错机制实施（沙箱 + 回放 + Gate）
- V3：自我进化元层实施（元控制器闭环）
- V4：突破设计师角色驱动验证（移除人工路由表，元层自主演化）
- V5：集成收口（端到端回测 + 安全审查 + 最终方案）
